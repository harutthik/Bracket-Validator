Bracket Validator using Stack

Bracket Validator is a simple and efficient program that checks whether a given expression has balanced parentheses using the stack data structure. It is a classic problem in Data Structures and is widely used in compilers and expression evaluation.

Features

Checks balanced parentheses (), {,

Fast and efficient using stack (LIFO principle)

Easy-to-understand logic

Beginner-friendly project

Useful for learning Data Structures

Objective

The main objective of this project is to: Understand how stack works (LIFO) Apply stack in real-world problems Validate expressions for correctness

How It Works

Opening brackets are pushed into the stack

Closing brackets are checked with the top of the stack

If matching pair → removed from stack

If mismatch or stack empty → invalid expression

At the end, if stack is empty → expression is balanced

✔ Technologies Used

Programming Language: C

Concept: Stack (Array Implementation)

Tools: GCC Compiler / Any C IDE
